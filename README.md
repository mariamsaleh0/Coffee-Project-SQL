# ☕ Coffee Data Analysis

## Project Overview
This project explores coffee-related data using SQL to practice data analysis, query writing, and extracting insights from data. Using DBeaver as my SQL editor, I wrote queries to explore the dataset, identify patterns, and answer questions about the data.

## Tools Used
- **SQL** — Data querying and analysis
- **DBeaver** — SQL editor and database management

## Project Goals
- Practice writing SQL queries to analyze data
- Explore patterns and trends within the dataset
- Use filtering, sorting, aggregations, and other SQL techniques to answer questions
- Strengthen my data analysis and problem-solving skills

Through this project, I gained more hands-on experience using SQL to explore data, write queries, and turn raw data into useful information.
